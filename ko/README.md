## 번역 원칙

기술 용어, 약어의 full name, 제품명, architecture 이름은 **영어 그대로** 사용합니다. 예를 들어 Training, Inference, Data parallelism, RDMA, MIG, TensorRT를 한글 음역으로 바꾸지 않습니다. 뜻과 동작 원리는 한글로 설명하여 영어 문항과 연결해 학습할 수 있습니다.

Diagram, 명령어, metric 이름, screenshot 안의 표기는 원본 영어를 유지합니다. Screenshot과 diagram은 각 문서의 한글 설명과 함께 읽으세요. Self-quiz의 문제, 상황, A–D 선택지와 진행 안내는 실전 대비를 위해 원본 영어를 유지하고, 해설만 한글로 제공합니다. 원본의 문항 번호와 정답표, 수치와 단위를 보존합니다. 확인된 오류는 원본 표기와 구분하여 교정 주석을 붙였습니다.

[번역 원칙과 원문 주의사항](translation-notes.md)을 함께 확인하세요.

번역은 저장소 원본을 기준으로 합니다. 원본의 시험 정책, 제품 사양, 성능 예시는 번역 과정에서 최신 정보로 갱신하지 않았습니다. 응시 전에는 [NVIDIA 공식 certification page](https://www.nvidia.com/en-us/learn/certification/ai-infrastructure-operations/)에서 현재 안내를 확인하세요.
